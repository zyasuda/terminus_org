# スタンディー着せ替え体験 設計提案(ガレス試作)

依頼文 `/private/tmp/standee-game-experience-request.md` だけを根拠に書いた。時間はすべて目標値で、実測ではない。採否は作者が決める。

## 結論

- **自由配置と自然さは「自由に動かせるのは決められた線の上だけ」にして両立させる。** 鞘は腰帯をぐるりと回る1本の輪の上を動かす。輪の上ならどこに置いても破綻しない絵になるように素材側で用意しておく。
- **前面と背面は「輪の上の1つの位置」から両方の絵を決める。** プレイヤーが動かすのは1つの値だけで、背面はそこから自動で決まる。だから前後で食い違わず、プレイヤーが直す場面も生まれない。
- 剣は「完成済みの握った手＋剣」を差し替えるだけにする。握りは素材を作る段階で解決しておき、プレイヤーには触らせない。

---

## 1. 初回の身支度(30秒が目標)

```
┌────────────────────────────────────────────┐
│                                            │
│              [ ガレス(正面) ]              │  ← 画面の主役。手ぶら、鞘なし
│                                            │
│                                            │
├────────────────────────────────────────────┤
│ 道具棚:  [片手剣A]  [片手剣B]  [鞘]         │  ← 棚に3つだけ
└────────────────────────────────────────────┘
```

| 秒(目標) | 画面 | プレイヤーの操作 | 返ってくる反応 |
|---|---|---|---|
| 0–3 | 手ぶらのガレスと道具棚 | なし | ガレスが棚のほうを見る。説明文は出さない |
| 3–8 | 棚 | 片手剣Aを**つまんでガレスへドラッグ** | 手の近くで吸い付き、握った手＋剣に差し替わる。軽い「チャキ」 |
| 8–12 | 剣を持ったガレス | 鞘をつまんでガレスの腰へドラッグ | 腰帯の輪が一瞬光る。輪の近くで放すと腰に付く |
| 12–20 | 鞘付きのガレス | 鞘を**輪に沿って**左腰〜背中〜右腰へ滑らせる | 角度と前後の重なりが自動で付く。決まりの良い位置で軽く止まる(磁石感) |
| 20–26 | 同上 | ガレスを**横へスワイプ**してくるっと回す | 背面に切り替わる。鞘は同じ位置のまま裏側から見える |
| 26–30 | 正面へ戻る | 「出発」 | 決めポーズ1枚。この見た目が本編の外でも記憶される |

剣Bは2回目以降に使う(持ち替え・鞘に納める)。初回は「持たせる」「鞘を置く」「回して眺める」の3つの気持ちよさに絞る。

## 2. 最小の遊び:棚 → 手に取る → 装備 → 整える → 前後を眺める

```
 道具棚 ──つまむ──▶ 手元(ドラッグ中) ──放す──▶ 装備
                                              │
                    ┌─────────────────────────┘
                    ▼
                  整える(鞘を輪の上で滑らせる / 剣を持ち替える)
                    │
                    ▼
                  眺める(スワイプで正面⇄背面)
```

| 段 | プレイヤーがすること | 裏でやっていること(プレイヤーには見せない) |
|---|---|---|
| 手に取る | 棚の道具をつまむ | 道具の小さな絵をドラッグさせるだけ |
| 装備 | ガレスの上で放す | 剣:握った手＋剣の完成素材へ差し替え。鞘:輪の最寄り位置へ吸着 |
| 整える | 鞘を輪に沿ってドラッグ。剣はもう1本をドラッグすると持ち替え | 指の位置を輪の上の1つの値へ投影。その値から角度・重なり順・背面の絵を決める |
| 眺める | ガレスを横にスワイプ | 同じ値で背面を描く |
| 外す | 道具をつまんで棚へ戻す | 元の状態へ |

### 自由配置と自然さの両立(要点)

```
         正面から見た腰帯の輪(上から見ると円)

              背中(奥:体の後ろに隠れる)
                ・ ・ ・
            ・           ・
     右腰 ・               ・ 左腰     ← 鞘はこの輪の上だけを動く
            ・           ・
                ・ ・ ・
              腹(手前:体の前に出る)
```

- 輪の上ならどの位置でも「鞘の角度」「体の前か後ろか」「背面での見え方」が1つに決まる。プレイヤーが壊せる自由度を最初から持たせない。
- 輪の外で放した場合は、最寄りの位置へ吸い寄せる。破綻した位置に置けないので、修理の場面が生まれない。
- 決まりの良い位置(左腰・背中斜め・右腰など)には軽く止まる磁石を付ける。止まるのは手触りのためで、通り過ぎることもできる。
- 剣の握りはプレイヤーに触らせない。持ち替え先(右手/左手/鞘に納める)を選ぶだけにする。

## 3. 2案の比較

| | A案:腰帯の輪(推奨) | B案:置き場所の札 |
|---|---|---|
| 鞘の動かし方 | 輪に沿って連続的に滑らせる | 左腰・右腰・背中など4〜6か所へドラッグで置く |
| 手触り | 「滑らせて好きな所で止める」楽しさがある | 「ここに置く」と決める気持ちよさ。微調整はできない |
| 自然さの保証 | 輪の全周で破綻しない素材が必要。中間の位置が難所 | 札の数だけ作れば済む。保証しやすい |
| 正面背面の整合 | 1つの値から両面を出す仕組みが必要 | 札ごとに正面・背面を対で用意するだけ |
| 素材準備の量 | 多い(連続的な角度・重なりの切り替わり) | 少ない(札の数×2面) |
| 避けられるリスク | 「選ばされている」感じ、どうぶつの森的な自由さの欠如 | 中間位置での破綻、背中側へ回る瞬間の重なり順の飛び |

**推奨の順序**:B案の札の位置を、A案の輪の上の「磁石が止まる位置」と同じにして先に作る。B案で作者が触って楽しければ、札の間を補ってA案へ広げる。逆にB案で十分ならA案の素材準備を省ける。

## 4. 初期に不要な機能

- 色替え・素材の差し替え・自作素材の取り込み(ツール化に寄る)
- 複数キャラクター、2本目の鞘、盾や背負い物
- 回転・拡大縮小・自由な角度変更(破綻の入口になる)
- 斜め視点や中間の向き(正面と背面の2面だけで足りるか先に見る)
- 取り消し履歴(外して棚に戻せば元に戻る)
- 保存枠・共有・撮影モード(「出発」の1枚で足りるか先に見る)
- 本編との連携

## 5. 作者が実クリックで判断する問い(5問)

1. 剣をガレスへドラッグして**手に吸い付いた瞬間**、「持たせた」と感じるか。それとも自分で手の位置へ合わせたいか。
2. 鞘を**輪に沿って滑らせる**(A案)と**札へ置く**(B案)で、同じ鞘・同じガレスを触り比べてどちらが楽しいか。
3. 磁石で止まる位置は**多すぎ・少なすぎ・ちょうど**のどれか(止まる強さは私たちが決めて見せ、気になった点を言葉で返してもらう)。
4. 横スワイプで背面へ回したとき、**鞘が「同じ鞘が裏から見えている」と感じるか**。違和感がある位置はどこか。
5. 30秒の身支度のあと、**もう1回やり直したくなるか**(剣Bに持ち替えたい、鞘を別の所へ置きたい、など)。

## 6. 未検証の課題

- **背中側へ回る瞬間の重なり順**:鞘が体の前から後ろへ切り替わる位置で、絵が飛んで見えないか。輪の上のどこで切り替えるかは素材を見て決める必要がある。
- **輪の全周で破綻しない素材を用意できるか**:A案の中間位置の数だけ素材が要るのか、少数の素材から補えるのか未確認。
- **完成済みの握った手＋剣が、ガレスの腕の位置と自然につながるか**:差し替えた瞬間の段差。片手剣2本で同じ握りを共有できるかも未確認。
- **剣を握った手と鞘が重なる位置**:鞘を腹側へ回したとき、握った剣と鞘が重なる場合の見え方。
- **30秒は目標で未計測**:実際に作者が触った時間と、迷って止まった場所を測る必要がある。
- **スワイプで回す操作が鞘のドラッグと衝突しないか**:ガレスの上で横に動かしたとき、回したいのか鞘を動かしたいのかの判別。
