## 2026-10-09：UI改善（`UI_TASK.md`）

上の「実装した範囲」のうち、次の点を置き換えました。見た目の採否は未判定です（Codexと作者が画面で判断）。

- **衣装掛け**：小さい全身ガレスの絵を撤去。CSSの真鍮棒と空のハンガー2本に札「鎧は着用中」「替え衣装は準備中」。画像の新規生成なし。
- **操作カード**：棚の「棚へ戻す」と台の下の常時の納刀/抜刀ボタンを撤去し、操作を人物のそばの小さいカード1か所に集めた。
  - 剣を持つ手、または鞘を押して離すとカードが出る（剣：納刀する/抜刀する/棚へ戻す のうち今できるもの、鞘：棚へ戻す）。納刀中の剣は鞘を押しても出ないので、台の下の「剣を整える」から開く。
  - 台の下の「剣を整える」「鞘を整える」は同じカードを開く入口（キーボード・支援技術向け）。着けていない品のボタンは出ない。
  - 操作・前後の切替・Esc・カードの外を押すと閉じる。品が棚へ戻るとカードも消える。
  - 押してから6キャンバスpx以上動かすとドラッグ扱い（`wardrobe.js` の `DRAG_SLOP`）。ドラッグ終了ではカードを開かない。手の当たり半径は `HAND_RADIUS`（70）。
- **鞘の取り付け枠**：鞘を棚から運ぶ間・台の上でドラッグ中・鞘のカードを開いている間だけ、腰の基準点を中心に±24pxの真鍮枠と、いまの位置の小さい点を描く。範囲（`SCABBARD_RANGE`）は変えていない。枠は動かせる範囲を示すだけで、素材どうしがつながる位置を保証しない。
- **装着の反応**：棚から着けたとき・納刀/抜刀のとき、人物が0.45秒ほど光って3px浮く。`prefers-reduced-motion: reduce` では動かさない。
- **案内の位置**：棚の使い方は棚の見出しの下、運んでいる間と身支度後の案内は人物の足もとに出す。開発注記は床の `試作について`（details）に畳んだ。
- **狭い画面**：幅760px以下はガレス→棚→衣装掛けの縦並び。390px幅で横あふれなし（変更前は scrollWidth 862px、変更後 390px。実測）。

`browser-check.cjs` のスクリーンショットは `screenshots/ui-*.png`。旧 `01〜06` は変更前の版として残している。`ui-before-*` / `ui-after-*` は同条件（1440×960と390×844、素手と抜刀）の変更前後。
