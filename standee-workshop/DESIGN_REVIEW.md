## 結論

- **「身支度台」を「衣装部屋」へ置き換え、触る場所を3つに分けます。** 小道具棚（品を取る）、俳優の立ち位置＝回転台（着ける・整える・回して前後を見る）、舞台袖の出口（身支度を終える）。1つの場所に1つの役目だけを置きます。
- **前後の確認は「鏡」ではなく「回転台」にすることを推奨します。** 鏡は正面を左右反転して映すため、CONCEPT §9 の「反転画像を背面として流用しない」と見た目の約束が食い違います。
- **鞘は「腰帯の輪を一周」から「左腰の弧の範囲だけ」に縮めます。** 前回提案の「輪の上ならどこでも自然」「前後が食い違わない」は保証できていません。成立させるには、位置ごとの前後素材と対応表を作者が目で承認する必要があります（§4に条件を列挙）。
- **作者が楽しいと言った手触りは残します。** 剣を手へ持たせる、鞘を腰へ置いて少し動かす、の2つです。手首・指・柄の接続は素材側の責任とし、プレイヤーには触らせません。
- 衣装掛けは、ガレスの替え衣装が無い初回では**置かない**ことを推奨します。触れるのに選べるものが無い場所になるためです。

## 3. 比較案（2つ）：鞘の整え方

剣の握りはどちらの案でも動かせません。違いは鞘の動かし方だけです。同じガレス・同じ剣A・同じ鞘で触り比べられるよう、ここだけを変えます。

### 案1：腰帯に沿わせる

- 体験：鞘をつまむと左腰のベルト上に短い弧が浮かぶ。弧の上なら好きな所へ滑らせて止められる。鞘の先端をつまむと、決められた幅の中で少しだけ傾く。弧の外で放すと最寄りの位置へ戻る。
- 残る手触り：作者が「意外と楽しい」と言った、目で見て位置を決める感覚にいちばん近い。
- 必要な素材：弧の両端と中間数か所での前面の見え方、背面の対応位置、吊り革がベルトへ届く絵。中間位置は回転と移動の補間で破綻しないかが未検証です。
- 避けられるリスク：「選ばされている」感じ。
- 残るリスク：補間した中間位置で、背面との食い違いや吊り革の浮きが出る。

### 案2：留め具を選ぶ

- 体験：左腰のベルトに留め具が3つ見える（前寄り・真横・後ろ寄り）。鞘を近づけると最寄りの留め具が光り、放すとそこへ掛かる。掛けた後の微調整は無い。
- 残る手触り：「ここに掛ける」と決める手応え。滑らせる楽しさは無い。
- 必要な素材：留め具3つ×前後2面の絵と、それぞれの対応。数が決まっているので作者が全部を目で承認できる。
- 避けられるリスク：中間位置の破綻、背面の未調整状態がプレイヤーに見えること。
- 残るリスク：作者が楽しいと評価した「位置を自分で決める」手触りが薄れる。

推奨：**案2の3か所を先に用意し、それを案1の弧の両端と中間にも使います。** 案2で手触りが足りないと作者が判断した場合だけ、3か所の間を補って案1へ広げます。素材の作業が無駄になりません。

前回提案からの変更：前回のA案は背中・右腰まで一周する輪でした。右手で抜く片手剣を右腰や背中に吊るす場面は初回に要らず、体の前後で重なり順が切り替わる難所（前回§6が挙げた課題）を最初から抱えることになります。弧を左腰だけに縮め、この難所を初回の範囲から外しました。

## 4. 自由に調整してよい範囲と、素材側が受け持つ範囲

| 対象 | プレイヤーが決めてよいこと | 素材側（舞台裏）が受け持つこと |
|---|---|---|
| 剣（握りセット） | どの剣を持つか。持つ・外す・鞘へ納める | 手・指・親指・手首・袖口の接続、柄の向き。位置と角度は固定 |
| 鞘 | 案1：左腰の弧の上の位置と、決められた幅の傾き／案2：3つの留め具のどれか | 範囲の各位置での前面の絵、重なり順、背面の対応位置 |
| 吊り革 | なし（鞘に付いてくる） | 各位置でベルトへ届く絵 |
| 前後 | 回転台で見る向き | 前面の配置に対応する背面の配置 |

### 「自然に見える」「前後が食い違わない」と言えるための条件

前回提案はこの2つを保証できるように書いていましたが、素材も対応表もまだ無いので保証できていません。成り立つには次がそろう必要があります。

1. **位置ごとの前後対応表。** 鞘の各位置（案2なら3か所、案1なら両端と中間）について、前面の位置・角度・重なり順と、背面の位置・角度・重なり順を1組にした表。現在あるのは背面を24px動かした候補1つだけで、採用は未確認です（CONCEPT §12）。
2. **その表を作者が目で承認していること。** 単純な左右反転（x' = 幅 − x）は位置の目安にすぎない、と CONCEPT §9 にあります。
3. **吊り革を鞘から分けた素材。** 現在は鞘画像に描き込まれていて一緒に動きます。図形で足した候補は、1131画素のうち258画素が人物の透明な隙間へ出ていて採否保留です（CONCEPT §13）。
4. **案1の場合、中間位置の補間で破綻しないことの確認。** 未検証です。
5. **剣Bの握りセット。** 未制作です。剣Aと同じ手を使って刃だけ替える案も未検証です（CONCEPT §7）。

これらがそろうまで、プレイヤーが動かせる範囲は**承認済みの位置だけ**に絞ります。背面が未調整の位置へ置けてしまう作りにすると、「背面は未調整」という制作側の表示をプレイヤーに見せることになるからです。

## 5. 衣装部屋に置く物・置かない物

| 物 | 初回 | 理由 |
|---|---|---|
| 小道具棚 | 置く | 品を取る唯一の場所 |
| 回転台 | 置く | 前後を見る唯一の操作 |
| 舞台袖の出口 | 置く | 身支度を終えて保存する唯一の操作 |
| 衣装掛け | **置かない（推奨）** | ガレスの替え衣装が無い。触れても選べない場所は誤った入口になる。替え衣装の素材ができた時点で置く |
| 姿見（鏡） | **置かない（推奨）** | 鏡は正面を左右反転して映す。反転しない背面を「鏡で見た」とすると見た目の約束が崩れる。合わせ鏡にする案もあるが、背面を映す理屈が回転台より分かりにくい |

衣装掛けを背景の絵としてだけ描く案もあります。部屋らしさは増しますが、触れそうに見えて触れない物が1つ増えます。どちらにするかは作者の判断です。

### プレイヤーの画面に出さない物（舞台裏へ）

数値、レイヤー、マスク、生成プロンプト、スライダー、背面の調整状態、素材の承認状態。これらは CONCEPT §5 の「素材を整える」側へ置きます。衣装部屋の画面から舞台裏へ入る扉は付けず、試作を開くときの入口で分ける案です。入口の位置は未決です。

## 6. 前回提案からの変更理由（まとめ）

| 前回提案 | 見直し後 | 理由 |
|---|---|---|
| 身支度台・道具棚の汎用画面 | 衣装部屋（棚・回転台・出口） | 作者の最優先の位置づけ（CONCEPT §18、REQUEST） |
| ガレスを横スワイプで回す | 足元の回転台で回す | 鞘ドラッグとの衝突を、場所を分けて避ける |
| 腰帯を一周する輪 | 左腰の弧（案1）／留め具3つ（案2） | 体の前後が切り替わる難所と素材量を初回から外す |
| 「輪の上ならどこでも自然」「前後は食い違わない」 | 条件付き。承認済みの位置だけ動かせる | 素材も対応表も未作成で、保証していない |
| 回転・拡大縮小をすべて外す | 鞘の傾きだけ幅を決めて残す（案1） | 作者が評価した「位置を目で決める」手触りを消さない |
| 「出発」と決めポーズ | 「舞台袖へ」と既存の前後画像を並べた1枚 | 衣装部屋の出口として通じる。新しい絵を前提にしない |
| 剣Bを棚に並べる | 布の掛かった棚として見せ、触れない | 未制作の素材を完成扱いしない |
| 取り消し履歴を外す | 外したまま。棚へ戻す・置き直すで足りるか実クリックで確かめる | 位置の範囲を絞ったので壊れた状態が生まれにくい。足りなければ戻す |

## 7. 作者が実クリックで判断する問い（4問）

1. **剣Aを右手の近くで放したとき、「持たせた」と感じるか。** 自分で手の位置へ合わせたくなるなら、吸い付く距離か握りの固定を見直す。
2. **案1（弧を滑らせる）と案2（留め具に掛ける）を同じガレスで触り比べ、どちらをもう一度触りたいか。** 案2で足りるなら案1の素材作業を省ける。
3. **回転台で背面にしたとき、同じ剣・同じ鞘として許せるか。** 許せない位置があれば、その位置を範囲から外すか対応表を直す。
4. **棚・回転台・出口の3つで、舞台に出る前の衣装部屋に見えるか。** 足りない物があれば言葉で挙げてもらう（衣装掛けを背景だけ置くかどうかもここで決める）。

楽しさと所要時間は、この実クリックで作者が感じたことと、迷って止まった場所の記録で判断します。本書では測っていません。

## 8. 未検証のまま残る事項

- 案1の中間位置の補間で絵が破綻しないか。
- 吊り革を鞘から分けた素材を作れるか。
- 納刀素材と空の鞘素材の柄・寸法差を、同じ剣に見えるところまで詰められるか。
- 剣Bで剣Aの握りを再利用できるか。
- 回転台の回る演出（瞬時の切り替えか、短い回転の動きか）。今の素材は正面と背面の2枚だけなので、途中の向きは無い。
- 「舞台袖へ」の後に衣装部屋へ戻る導線。独立試作では本編に戻らないため、戻り先は試作の範囲で決める必要がある。
