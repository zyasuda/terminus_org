# 衣装部屋：Codex・Claude設計議論の整理

2026-10-09。作者の依頼で2往復。実装・生成・採用は行っていません。

## 結論（次に検証する候補）

「完成済みの手＋道具」と「衣装側の袖口・籠手の縁」を分ける方式を、最初の候補とします。自然な握りは素材側で成立させ、プレイヤーは棚から手へ渡して装着します。鞘や腰小物には自分で配置する楽しさを残します。

これで全装備へ一般化できたわけではありません。同じキャラ・同じ手首位置・同じ腕姿勢で検証します。棒、ランタン、盾、両手武器は別の握り/姿勢が必要な候補です。

## 往復で何が変わったか

1. Claudeは当初、奥の掌と手前の指で柄を挟む方式を推奨しました。
2. Codexは、隠れた掌や接触影が新柄で露出する問題と、一体方式だけに衣装ごとの費用を課した比較の不公平を指摘しました。
3. Claudeは「手＋道具一体、袖口は衣装側」を比較へ追加し、これを基本候補へ変更。指の挟み込みは後の実験へ下げました。
4. 同じ握りIDがあれば前後が整合する、同じ拳で松明も持てる、という断言を撤回しました。
5. 袖口の所属や画像規格は技術側が検証すべき事項として、作者に先に選ばせる問いから外しました。

## 衣装部屋として守ること

プレイヤーは舞台俳優です。衣装掛け、小道具棚、前後を確かめる場所、舞台への出口で身支度を楽しみます。現在の鎧も「いま着ている衣装」として扱えます。替え衣装が無いことを偽らず、武器棚だけの画面に寄せません。

- 衣装・兜・靴：選ぶと変わる。
- 武器・手に持つ道具：手へ渡すと、自然な握りで装着する。
- 鞘・腰の小物：取り付け可能な範囲で、自分で整える。

以上は操作案です。作者の自由配置の楽しさを、単なるクリック選択だけに置き換える決定ではありません。登録済みの持ち方を切り替える案も将来候補として残します。

## 実装前の検証順案（今回は未実施）

1. 既存ガレスの前後の握り1組を並べる。親指/掌/甲、指の並び、持ち軸、手首の曲がり、柄と鍔の可視範囲を作者が確認する。
2. 袖口を別の遮蔽にして元の見え方を再現できるか。難しければ一体素材を維持する。
3. 2本目の剣で、手と道具の部品を追加する費用と見え方の差を確認する。刃だけの交換は、異なる柄や道具への対応を証明しない。
4. 鞘の前後対応を、身体の取り付け場所と作者が確認した位置の組で登録する。座標の左右反転だけで保証しない。
5. 後段で、指と掌に分ける握り方式、別の柄、別の握り型、替え衣装を試す。

画像枚数の比較は準備/修正の時間ではありません。2層方式は複数武器で手を同じに保ち、場合によっては武器ごとの手の生成を省ける利点もあります。現時点では、枚数だけを根拠に捨てません。

また、第2回答の「腕の幅や姿勢が変われば全品を作り直す」は最悪ケースの扱いです。必ず全面再制作になるとは断定しません。交換範囲/接続位置を変える案もあり、素材を見て決めます。今回の議論は画像を確認していないため、実験の代わりにはなりません。
