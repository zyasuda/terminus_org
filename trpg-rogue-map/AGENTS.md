## 絶対に守ること

### 1. 隣のフォルダを書き換えない

| 場所 | 扱い |
|---|---|
| `../trpg-gm-isometric/` | **読むだけ。** mock2本体で保全対象 |
| `../trpg-gamebook/` | **読むだけ。** 動いている作品 |
| `../trpg-gm-mock2/` | **読むだけ** |

必要な資産はこのフォルダへ複製してください。元を直さないでください。

### 2. 依存パッケージを追加しない

ビルド無し・依存0件の素のESMです。`npm install` を実行しないでください。
`package.json` の `dependencies` を増やさないでください。

### 3. `Math.random` を判定側で直接呼ばない

seedで再現できることが受入条件です。乱数は必ず `rng` を引数で受け取ってください。

### 4. 判定と描画を混ぜない

描画側にゲームの判定を持たせないでください。逆も同じです。

## 検証

```
npm run serve     # → http://localhost:8123/（キャッシュ無効）
npm test
```

**`python3 -m http.server` を使わないでください。** キャッシュで検証が空振りします。

**`npm test` が緑でも完了ではありません。** UIを変えたら実ブラウザで操作してください。
Playwrightはグローバルに入っています。

```js
import { chromium } from "/Users/yasuda_k/.nvm/versions/node/v20.14.0/lib/node_modules/playwright/index.mjs";
```

既存コードと同じ密度・同じ語り口に合わせてください。コメントは**なぜそうしたか**を書きます。

```js
// 良い: 0ダメージを「反撃。0ダメージ」と出すと、何も起きていないのに1行増える
```
