# B1遠征試作 — 計画

構想の正本は BORG `Inbox/ゲームブック_ローグ_ウィザードリィ融合構想_2026-08-14.md`。
ここには**このプロジェクトで実際に作るもの**だけを書く。

## 目標

物語主導のダンジョン探索RPG。ゲームブックを主役とし、ローグから未知の地図と経路選択を、
ウィザードリィから階層探索・帰還の緊張を借りる。

```
村 ──▶ 迷宮B1 ──▶ 探索 ──▶ 物語部屋 ──▶ 階段の解放
 ▲                  └──▶ 通常遭遇          │
 └──────────── 帰還 ◀────────────────────┘
```

## 決定済み（構想文書から引き継ぐ）

- ゲームブックを物語の主役として残す
- 階層つきローグ風探索マップと、村への帰還を加える
- 階段は原則として上下を往復可能にする
- 物語シーンの達成は、新階層または封鎖区画の**恒久解放**にする
- **地図・敵・資源は、区域の初回生成後は固定する。既知区域を再生成しない**
- 通常戦は殲滅を標準の勝利条件にする。複数戦略は強敵・ボスに集中させる
- ハスクラを入れる場合は、数値厳選より地図・物語・戦術を変える固有効果を優先する

「初回生成後は固定」が構想の背骨。ここを揺らすと、**プレイヤーが覚えた地理を奪う**ことになり、
そもそもの動機（位置関係が分からない）に戻ってしまう。

## 縦切りの順番（2026-08-14 決定）

構想文書の「試作に入れるもの」（6項目）は、生成・描画・物語接続・戦闘接続・保存の5層が
同時に入っており、縦切り1本ではない。**1本目を絞る。**

| 本 | 中身 | 通ったと言える条件 |
|---|---|---|
| **1本目** | seed付きB1生成器＋到達可能性検査＋2D探索地図 | 作者が初見で現在地・戻り道・階段を判断できる |
| 2本目 | 物語部屋の接続（gamebookを呼ぶ）と、達成による階段の解放 | 達成前は使えず、達成後に使える |
| 3本目 | 通常遭遇の接続（isometricを呼ぶ）と帰還・再開 | 遭遇は一回だけ／再開で状態が一致 |

**1本目が通らなければ、2本目を作る意味がない。** 元の動機は「位置関係が分からない」であり、
それに答えるのは地図であって、遠征モジュール一式ではない。

## 1本目に入れないもの

- 職業、レベル、呪文
- ランダム性能の装備、装備厳選、クラフト、経済
- 永久死亡
- 空腹、松明残量などのターン消費
- 遠征用エディタ
- B2以降
- **物語部屋の中身と、戦闘そのもの**（1本目では地点として置くだけ）

## 作者が手で書く最小データ（2026-08-14 訂正）

**作者は地図について何も書かない。** 当初はこういう `anchors` を書かせる想定だった。

```js
{ floorId: "mine_b1", roomCount: [5,7],
  anchors: [{ id: "junction", type: "story", sceneId: 2 }, ...] }
```

これは要らなくなった。生成器は**章のJSONをそのまま読む**（`scenes[].id` / `name` / `exits[].to`）。
部屋は章に書かれた場面そのもので、生成器は部屋を発明しない（D5）。

作者が守るのは1つだけで、それも既に守られている。

> **入口からの遠さの順序。** 灯りの部屋が入り口の隣に生成されたら、物語が壊れる。
> これは `exits` から機械が導けるので、作者が書く項目にはならない。

## 受入条件

コードの検査だけで終わらせない。

| # | 条件 | 測り方 |
|---|---|---|
| 1 | 100個のseedすべてで、入口から物語部屋と階段候補へ到達できる | 自動 |
| 2 | 同じseedなら同じ地図になる | 自動 |
| 3 | 物語部屋の達成前に下り階段を使えない | 2本目 |
| 4 | 帰還後の再開で、地図・探索済み・撃破済みが一致する | 3本目 |
| 5 | 未踏通路の通常遭遇は一回だけ起きる | 3本目 |

6はコードでは測れない。1本目の完了判定はこれ。

### 受入条件の訂正

条件1「100個のseedすべてで到達できる」は **「生成に成功したseedだけ使う」** が正しい。
衝突は生成した瞬間に検出できるので、失敗は捨てて振り直せばよい（V2）。
実データの本当の接続（閉路つき）では**1発で100%**（2000seed）。

### 新しく決まった前提

- リリースは**スマホのWebアプリ・縦持ち**（D12）。試作はブラウザ
- 移動は本文の選択肢から外し、**地図の上だけ**（D3）。絶対方向のみ、相対方向は使わない（D4）
- 一人称視点は、**シナリオ進行が起きたときだけ**の演出。移動は俯瞰のまま（D11）
