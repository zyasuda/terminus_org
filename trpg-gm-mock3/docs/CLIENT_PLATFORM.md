作者が先方から受け取った資料を、受け取った順に写す。先方の記述をそのまま残し、こちらの解釈は書かない。mock3 との対応は [SPEC.md](SPEC.md) と会話で扱う。
外部に見せる成果物へ転記するときは、先方名・ジャンル名を入れない。

## 1. 基本コンセプト(2026-11-06 受領)

参加者が物語の登場人物になりきり、会話と推理で事件の真相を解き明かす体験型ゲーム。

近い遊びとの関係:
- 人狼ゲーム: 会話と投票で正体を暴く
- 推理小説: 物語の中で真相に迫る
- 掛け合わせると: 会話で進む × 物語がある

特徴:
- **一人ひとりに秘密がある。** 各プレイヤーは、自分だけが知る秘密や目的を持っている
- **会話で進む遊びと、物語の面白さをあわせ持つ**
- **犯人も参加者の中にいる。** 犯人役のプレイヤーは、正体を隠したまま議論に加わる

## 2. 技術スタック(2026-11-06 受領)

## 3. 遊び方の流れ(2026-11-06 受領)

| # | 段階 | プレイヤーがやること | GMがやること |
|---|---|---|---|
| 1 | 配役 | キャラクターと資料を受け取る | 配役を決め、資料を配る |
| 2 | 導入 | 世界観と事件の概要を知り、自己紹介する | 物語の導入を読み上げる |
| 3 | 調査 | 証拠カードを入手し、手がかりを集める | 証拠カードを配る・公開する |
| 4 | 議論・密談 | 全体で話し合い、ときに1対1で交渉する | 時間を管理し、場を回す |
| 5 | 投票 | 犯人だと思う人物を指名する | 投票を集計し、結果を発表する |
| 6 | エンディング | 結末を迎え、真相が明かされる | 真相を解説する |

## 4. プラットフォームの位置づけ(2026-11-06 受領)

ボードゲームとして遊ばれているミステリーゲームを、WEB上で体験できるプラットフォーム。

| テーブルで遊ぶ | プラットフォーム上 |
|---|---|
| 紙のキャラクターシート | 画面上のキャラクター資料 |
| 手渡しの証拠カード | 画面上で配られる証拠カード |
| 同じ場所に集まる | オンラインのルームに集まる |
| 紙や挙手で投票 | 画面上で投票 |

※ GM(進行役)は人が担当する。

## 5. WEB化で解決すること(2026-11-06 受領)

| アナログで遊ぶときの壁 | WEBでの解決 |
|---|---|
| 人数と場所を揃えるのが大変 | オンラインのルームに集まるだけで遊べる |
| 秘密情報の配布・管理が煩雑 | プレイヤーごとに個別表示 |
| 証拠カードや投票の扱いに手間 | カード配布・公開、投票集計を自動化 |

## 6. このプラットフォームでできること(2026-11-06 受領)

| 機能 | 内容 |
|---|---|
| プレイヤー募集 | シナリオと日時を決めて募集できる。友人限定の募集も可能 |
| 通話・テキスト | アプリ内でボイス通話ができ、ほかのツールが不要 |
| ゲームの自動進行 | アプリがGM(進行役)の役割を担い、ゲームを進める |
| 手がかりの表示 | テキストや手がかりを画面に表示しながら進行できる |
| 得点計算 | ゲーム結果の得点計算もアプリ内で完結 |
| 感想トーク | 遊んだあとに参加者同士で感想を話せる |

募集からプレイ、遊んだあとの感想まで、アプリひとつで完結するのが特徴。

## 7. TRPGの親和性(2026-11-06 受領)

TRPGとは: 参加者がキャラクターを演じ、GMが進行する「会話で遊ぶRPG」。

物語をみんなで作っていく: GMの語りとプレイヤーの行動が重なり合い、物語が進んでいく。

TRPGで使うもの:
| もの | 役割 |
|---|---|
| シナリオ | 物語の舞台や展開の設定 |
| キャラクターシート | キャラクターの能力値や背景を記録 |
| ダイス | 行動の成否を判定する |

### 7.1 共通点: 遊びの構造がほぼ同じ(2026-11-06 受領)

| 項目 | TRPG | ミステリーゲーム |
|---|---|---|
| 遊びの中心 | 会話とロールプレイ | 会話とロールプレイ |
| 進行役 | GM | GM |
| 物語の土台 | シナリオ | シナリオ |
| プレイヤー情報 | キャラクターシート | キャラクターシート+秘密情報 |
| 遊ぶ単位 | セッション(数時間〜) | 1公演(数時間) |

### 7.2 異なる点(2026-11-06 受領)

| 項目 | TRPG | ミステリーゲーム |
|---|---|---|
| プレイヤー同士の関係 | 基本は協力して物語を進める | 秘密を抱え、推理・対立する |
| 情報の扱い | パーティ内で共有するのが基本 | 秘密情報がゲームの核 |
| GMの役割 | ルール判定や即興で物語を裁定する | 用意された進行に沿って場を回す |
| 判定の仕組み | ダイスとルールシステムで行動の成否を決める | 基本はダイスを使わず、会話と投票で決着 |
| 結末 | プレイ次第で展開が大きく変わる | 用意された真相に向かって推理する |
| 継続性 | 同じキャラクターで続けて遊べる(キャンペーン) | ネタバレの性質上、同じシナリオは基本1回きり |
