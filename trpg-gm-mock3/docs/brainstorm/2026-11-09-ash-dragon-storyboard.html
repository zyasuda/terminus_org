灰の竜と塔の魔法使い(仮)

「共通の目的+配られる秘密の札」で遊ぶ1回90〜120分のシナリオの流れを、ストーリーボードとして描いた案です。人物はmock3の4人をそのまま使います。舞台・ルール・合意の仕組みも、今のコードの資産を前提にしています。

あらすじと真相

山あいの村の上に、古い塔が建っています。そこに棲みついた灰の竜が、夜な夜な村を襲うようになりました。村長は4人の冒険者に依頼します。「竜を討ってくれ」。

真相(エンディングまで誰も知らない): 塔に住む老魔法使いヴェルンが、研究のために竜の卵を盗んだ。竜は卵を探して暴れているだけ。卵を返せば竜は鎮まって去る。ヴェルンは村長に口止め料を払っている。

共通の目的: 竜の脅威を村から取り除いて、生きて帰ること。これに失敗すると全員が負けます。秘密の札は、パーティが勝ったときしか達成できません。

結末を決める4つの選択

結末は、この4つの選択の組み合わせで決まります。判定はプログラムが行います。矛盾しない組み合わせは40通りです。

選択取りうる結果つながり
竜討つ / 鎮める / 縛る鎮めるのは、卵を返したときだけ。討つには、塔の財宝の中にある竜殺しの槍が要る。縛るのは、魔法使いの鎖の術だけ
卵返す / 持ち去る / 壊す返すと竜が鎮まる
魔法使い暴く / 手を組む / 自ら打ち明けさせる / 討つ「自ら打ち明けさせる」は、日記を読み解き、本人を説得したときだけ選べる。暴く側と組む側の両方の札を満たす、話し合いの道
財宝持ち去る / 山分けする / 槍に使う / 置いていく山分けは、金が欲しいガレスと、村の再建に充てたいイネスの両方を満たす交渉の道

秘密の札(1人3枚、毎回1枚を配る)

札はキャラクターの「根っこ」から作るので、どの札を引いても人物像はぶれません。条件はすべて、上の4つの選択だけで判定できる文にしています。

「全員達成できる回」は、その札が配られる27通りのうち、4人全員の札を満たす結末が1つでもある回の数です。

数えた結果(81通りの配り方を全部確かめた)

43%全員が達成できる結末がある配り方(35/81)。残りの57%は、誰かが必ず諦める
17/35全員達成の回のうち、「自ら打ち明けさせる」か「山分け」、つまり話し合いの道でしか届かない回
2〜4人最善の結末での達成人数。4人が35通り、3人が44通り、2人が2通り。全員が外れる配り方は無い

大団円の道があるかどうかは配り方で変わり、プレイヤーには分かりません。だから「打ち明ければ正解」にはならず、打ち明けるかどうかは毎回の賭けになります。いちばん厳しいのはブロムの「竜を討って仇を取る」(6/27)で、試遊で達成率を見て調整する候補です。

ストーリーボード(先方の6段階に沿って)

配役

札が配られる

画面
自分の人物シートと、伏せた札。めくると自分の秘密の目的が出る。他人の札は裏面だけ
知っていること
自分の札だけ
会話の理由
まだ無い。ここで秘密の重さが伝わるかが大事
2
導入

村長の依頼

画面
村の広場。GM(AI)が依頼を読み上げる。各自が「表の目的」だけで自己紹介する
知っていること
依頼は「竜を討て」。報酬の額は全員が聞く
会話の理由
討伐の報酬に、ガレスとブロムの札が反応する

ガレス: 満額なら、討つのが一番早いな。

3
調査

画面

イネスだけが「竜にやられたのに焼け跡が無い」と気づく。ブロムだけが「村長の家に塔の紋章入りの革袋」を見る
会話の理由
手がかりは見つけた本人だけが持つ。話すかどうかは本人次第(今のコードの仕組み)
4
調査

塔の麓の卵の殻

画面
塔の麓。灰に埋もれた殻の欠片と、破れた日記の切れ端
知っていること
マレンだけが、殻を竜の卵だと鑑定できる。日記の切れ端は、拾った本人だけが読める
会話の理由
「竜は卵を探しているのでは?」という仮説が生まれる。言えば竜を討たない流れになるので、討ちたい札の人は黙りたくなる
5

1対1の交渉

画面
塔の下での野営。宛先を1人に絞って話せる(今のコードの宛先選択を、人間どうしの密談に広げる)
知っていること
相手が何を知っているかは、話すまで分からない
会話の理由
山分けや取引は、全員の前では言いにくい

ガレス→イネス: 財宝の半分は村に回す。その代わり、宝のことは他の2人には黙っていてくれないか。
(竜を討つと財宝の槍を使うので、山分けとは両立しない。ガレスが「討伐の満額報酬」の札なら、この申し出は嘘になる)

議論(山場)

塔の最上階、竜と卵

画面
竜が卵の台座の前で唸っている。魔法使いヴェルンが鎖の術を構えて「討て」と叫ぶ

各自の手がかりと札。ここで初めて全員が同じ場面を見る

4つの選択を一度に迫られる。打ち明けるか、黙って押し通すか。リーダーは置かないので、誰も他人の行動を決められない

マレン: 待って。あの卵は、この竜のものよ。
ブロム: 戦わずに済むなら、それが一番だ。

7
決着

戦うか、鎮めるか

画面

選んだ道の危険。討つ道は激戦で、ブロムの「誰も倒れずに」と衝突する
会話の理由
途中で意見を変える人が出る。全員の確認が要るので、変えた人は説明しなければならない

エンディング

真相と達成表

画面
GMが真相を語る。4人の札を一斉にめくり、達成/未達を並べる。後日談を1人2行ずつ読む
知っていること
全部。「だからあの時渋ったのか」が起きる場面
会話の理由
感想トーク(先方の機能)へ自然につながる。順位は出さない

配り方の例2つ(検算済み)

例A: 大団円に届く回

ガレス「財宝を持ち帰る」/ マレン「禁術を暴く」/ ブロム「誰も倒れずに帰る」/ イネス「財宝を村の再建に」

全員が達成できる結末は4つあります。代表は「卵を返して竜を鎮める+魔法使いを暴く+財宝を山分け」です。ただし、ガレスとイネスが財宝について打ち明け合い、山分けに合意しないと届きません。どちらかが黙って持ち去れば、もう片方は未達になります。

例B: 誰かが必ず諦める回

ガレス「財宝を持ち帰る」/ マレン「卵を研究に持ち帰る」/ ブロム「誰も倒れずに帰る」/ イネス「竜を村から遠ざける」

全員の達成はできません。最善でも3人です。戦わずに竜を遠ざけるには卵を返すしかなく、それはマレンの札とぶつかります。ここでマレンが正直に話すと、イネスに先回りされて卵を返されます。打ち明けるのが損になる回です。

まだ分からないこと

  • 人間どうしで会話が続くか。ここに書いたのは設計上の理由で、確かめられるのは人間4人で遊んだときだけです。
  • AIの代役が秘密を抱えて振る舞えるか。今のAIは頼まれれば応じるように作ってあるので、渋る、探りを入れる、話をそらす、といった振る舞いを足す改修が要ります。
  • 4つの選択を山場で一度に迫ると、重すぎないか。2回に分ける案(塔の下で財宝、最上階で竜と卵と魔法使い)もあります。
  • 人が集まらない中で、何を先に確かめるか。作者+AI3人の試遊では、流れと所要時間は確かめられますが、人間どうしの駆け引きは確かめられません。AIだけで多数回遊ばせると、札の達成率の偏りは測れます。
