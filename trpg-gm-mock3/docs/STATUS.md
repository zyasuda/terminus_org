# mock3 実装状況(2026-11-06 時点)

## 結論

**シナリオ1本(坑道入口 → 排水 → 石扉 → 番人戦 → 結末)は、人間1人+AI3人で最初から最後まで遊べる形で実装済み。** オフラインの自動検査は12本中11本が通る。
ただし、遊べることを実AIで戦闘の結末まで通して確かめたのは 2026-10-04(ローカルGemma)が最後で、それ以降(Claude Haiku 5.5 に切り替え、装備の着脱・素体開始を追加した後)は未実施。
企画の柱のうち「複数人が声で遊ぶ」部分(複数端末の同期・音声通話・声の文字化)は未着手で、今は1人で遊ぶ連携の試作にとどまる。

仕様は [SPEC.md](SPEC.md)。

## 1. 企画の柱ごとの到達度

| 柱(SPEC 1.2〜1.4) | 状態 | 根拠 |
|---|---|---|
| (1) 相談が要る決定 | 一部 | 戦闘は全員の行動をそろえて実行。探索の合意はランタンの点灯・消灯の1議題だけ |
| (2) その人にしかできないこと | 実装済み | 役割ごとの行動・個人所有の道具。手放すと能力も使えない |
| (3) 出番が回ってくる | 未実装 | 「迷っている」人への声かけ・停滞の自動判定は無い |
| (4) 情報が人ごとに違う | 実装済み(1人分) | 手がかりは見つけた本人だけが知り、会話で共有する。人物設定も会話で知った分だけ見える。ただし人間が1人なので、人間どうしの偏りは試せない |
| 判定はプログラム、語りはAI | 実装済み | AIの返答は行動案として検査してから実行 |
| 4人の人間がネット越しに声で遊ぶ | 未着手 | 端末同期・通話・声の文字化(案C)は無い。マイクは自分の1発言をブラウザーで文字にするだけ |
| 1回90〜120分 | 未測定 | 坑道シナリオは3場面+戦闘で、時間は測っていない |
