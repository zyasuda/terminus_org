# 立ち絵制作ツール（2026-10-08）

主入口は `index.html` の**制作フロー**：①納刀を決める → ②抜刀を作る → ③素手を作る。画像生成はしない。使い方は `guide.html`。

- ①：完成した納刀の正面・背面を読み込み、並べて確認して「基準として保存」。基準はこの操作でだけ変わる。
- ②③：基準が無いと始められない。各向きで「編集用プロンプトをコピー」→（ツールの外で生成AIへ納刀画像と一緒に渡す）→「できた画像を読み込む」→「基準と比較する」（基準と同じ寸法で並べる）。
- 「制作データを保存／開く」：画像込みJSON（`kind: "standee-flow"`）。詳細レイヤー編集のJSONとは別形式で、取り違えるとエラーで知らせる。「この段階のPNGを保存」：表示中の段階を向きごとのPNGで。
- 「試作デモ（ガレス）を開く」：`studies/gareth-sword-v1/state-{sheathed,drawn,empty}.json` を core.js で合成して読み込む（採否は未判定）。
- 状態の検査・依頼文は `flow-core.js`、画面は `flow.js`。

以下は**詳細レイヤー編集**（`layer-editor.html`、手引きは `layer-editor-guide.html`）。固定した素体に装備パーツを重ね、正面と背面を同じ縮尺で並べて比べる。生成AIへ渡す依頼文と、接続点付きの参照ガイドPNGを作るところまで。

## 起動

ログイン・APIキー・ゲームのAIは不要。リポジトリ直下（`trpg-gm-mock3/`）から静的配信して開く。

```sh
cd ~/Desktop/Terminus/trpg-gm-mock3
python3 -m http.server 8765
# ブラウザーで http://127.0.0.1:8765/tools/standee-layer-editor/（詳細は layer-editor.html）
```

`file://` で直接開くと「試作デモ（ガレス）」「ガレス既存素体」の読込（fetch）が失敗する。ほかの機能は動く。

## できること

- 各面4レイヤー（奥から：奥の装備／素体／手前の装備／交換手・遮蔽指）。ローカルPNG読込、表示切替、外す。
- 選択レイヤーをドラッグ・矢印キー（Shiftで10px）で移動。位置・回転・縮尺を数値入力（範囲外は反映せずエラー）。
- 元の手を隠すマスク（矩形の追加・削除・数値）。**素体だけ**に掛かり、装備レイヤーは消さない。
- 接続点（各面のx/y）、アクリル外枠の参照画像（表示切替）、拡大表示。
- 透明PNG書き出し（前後2枚、接続点・マスク枠・外枠を含めない）、参照ガイドPNG（素体を薄く＋接続点＋外枠）。
- 設定を画像込みJSONで保存・復元。壊れたJSON・範囲外の値・読めない画像はエラー表示し、今の作業を残す。
- 依頼文：武器種・外観・方式（手首交換／固定指）・持ち手。前後の画面上の左右、接続点、固定条件、素体を再生成しない・反転で流用しない旨を含む。コピー可。

## 素材

- **デモ図形**：自作の幾何図形。実キャラ画像ではない。
- **ガレス既存素体**：`prototype/art-preview/gareth-equipment-study/gareth-empty-front.png` と `gareth-empty-back-natural.png` を読むだけ。合成結果の採否は作者が判断する（このツールは何も採用しない）。
- 前後は別画像として扱う。反転で代用する機能は無い。

## 上限

JSON 4000万文字、画像1枚15MB・一辺4096px、マスク50個/面、位置±5000、回転±360°、縮尺0.05〜10。キャンバスは656×1199固定（ガレス素体の寸法）。

```sh
node check.cjs           # 合成順・素体限定マスク・保存復元・不正入力・依頼文、制作フローの基準保持・保存復元・不正データ・編集用プロンプト
node browser-check.cjs   # 実ブラウザー操作（詳細レイヤー編集と制作フロー）。screenshots/ に保存
```

`browser-check.cjs` は依存を追加せず、`../../../trpg-gm-mock2/node_modules/playwright` を借りる。mock2側に無ければ動かない。
