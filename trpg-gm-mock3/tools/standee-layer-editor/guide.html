立ち絵制作の使い方

完成した「納刀」の絵を基準にして、「抜刀」と「素手」を作ります。正面と背面は別々に作ります。

制作フローを開く →

3つの工程

①納刀を決める

完成した納刀の正面・背面を読み込み、並べて確認して基準として保存。

→
②抜刀を作る

基準を編集。鞘から柄を消し、右手に剣を持たせる。

人物姿勢鞘の位置・長さ・角度
→
③素手を作る

基準を編集。剣と鞘を取り除く。

人物姿勢

紺の札は「変えないもの」です。②③は必ず①の基準から作ります。

②③の進め方（正面・背面それぞれ）

  1. 編集用プロンプトをコピー
  2. 生成AIに、コピーした文と①の納刀画像（同じ向き）を渡して編集してもらう（ツールの外）
  3. できた画像を読み込む
  4. 基準と比較するで、人物・姿勢・鞘がずれていないかを同じ寸法で見比べる
人物の右手は、正面図では画面の左、背面図では画面の右にあります。プロンプトには両方を書いてあります。左右反転した画像で代用しないでください。

保存と再開

ボタン使う時
制作データを保存画像込みで今の作業を保存。続きは制作データを開くで再開
この段階のPNGを保存（正面・背面）表示中の段階の絵を、向きごとのPNGで受け取る
試作デモ（ガレス）を開く既存のガレス3状態で動きを試す（採否は未判定）
基準は基準として保存を押した時だけ変わります。読み込みに失敗しても、表示中の画像は消えません。未保存のまま閉じようとすると確認が出ます。

起動

リポジトリ直下で python3 -m http.server 8765 を実行し、http://127.0.0.1:8765/tools/standee-layer-editor/ を開きます。file:// で開くと試作デモだけ読めません。

詳細レイヤー編集

装備パーツを素体に重ねて位置・回転を合わせる画面です。普段の制作では使いません。詳細レイヤー編集（その手引き）
