# 坑道の向こう：連携UI試作

起動：`node prototype/preview.cjs`

開く：<http://127.0.0.1:8797/prototype/index.html>

検査：`node prototype/check.cjs` と `node prototype/profile-check.cjs`

既存の `../trpg-gm-mock2/server.cjs` とそのAI設定を利用します。既存ファイルは変更しません。8797は画面、8798はAI中継に使います。AIの入出力ログは `/tmp/mock3-llm.jsonl` へ出ます。新しい依存パッケージはありません。

あなたはイネス、他の3人は実際のLLMが発言と行動を選びます。会話の宛先はデフォルトが全員で、全員を選ぶと3人が順に応答します。ブロム・ガレス・リディアをアイコンで選ぶと、その1人だけが返答します。会話は全員に聞こえ、共有情報として記録します。相談中のAIは実行せず、手がかりの共有と行動の提案をします。明示した依頼または戦闘作戦だけを実行し、対象の状態や戦闘結果はJavaScriptで処理します。自由文は原則として相談ですが、リディアへの明示した点灯・消灯の依頼はJSが実行します。それ以外の実行は行動ボタンから行います。

探索：リディアに点灯を頼む → 台車を調べて工具を拾う → 排水室でブロムに操作輪の支援を頼む → 工具で排水する → 広間へ戻る → ガレスの鍵開けとブロムの支援 → 工具または留め具で開扉。

リディアの持ち物「古い坑道の地図」から、3シーンの手書き風の略図を開きます。初期は入口だけ、点灯すると見つけた道を点線で描き、訪問すると実線になります。移動は地図からではなくシーン内の出口ボタンから行います。再訪して初めて広間の変化が表示されます。全員が調査でき、結果は各キャラクターだけの情報になります。レールなど進行条件にならない調査点もあります。工具には排水と扉の固定の2用途があり、扉を破壊する別ルートでは番人が強くなります。背景画像は既存素材の仮配置です。
戦闘：自分の行動を選ぶ → 各AIが自分の行動を選ぶ → 順番を提案 → 仲間と連携を調整 → 本人たちの了承後に実行。

この画面内の1卓だけの試作です。音声通話、複数端末同期、保存、任意の自由行動の裁定、自動的な停滞検知は未実装です。GM介入は入力欄の宛先で「GM」を選んで試せます。画面・戦闘数値・配役は新しい仮案で、既存シナリオの仕様を変更しません。

AIによる試遊は操作とルールの確認に使えますが、人間の遊び心地の証明にはなりません。

GM表示：mock2の images/gm_mascot.png をコピーして使用。会話ログと「相談・発見を仲間に伝える」入力欄の間に高さ160pxの専用スペースを配置し、初期位置は右端です。GMをドラッグ、またはフォーカスして矢印キーで移動できます。範囲外へは出られず、シーン移動や発言で置いた位置は変わりません。位置は再読み込みで戻ります。移動中は歩行風の上下動と傾き、待機中は呼吸風の動きと4.8秒周期の簡易瞬きを表示します。吹き出しは10秒で閉じ、全文は会話ログに保持します。1枚絵とCSSを使った簡易表現です。動きを減らすOS設定ではアニメーションを停止します。自動停滞介入は未実装です。

会話ログ：発言が少ないときは下寄せし、最新を末尾に追加します。末尾を見ているときだけ新着を自動追従し、過去ログ閲覧中はスクロール位置を維持します。

GMは専用スペースの左半分では画像と目ぱちを一緒に左右反転し、右半分では元の向きになります。歩行・発話のアニメーションは維持します。

会話欄：「>>」で畳むとメインシーンが広がり、右端にGMと「<<」ボタンを残します。畳んだ間の新着は未読件数で表示し、自動では開きません。境界をドラッグすると240〜420pxで幅を調整できます。境界にフォーカスして左右キーでも調整でき、Homeで最小、Endで最大です。狭い画面では縦並びを保ち、幅調整を隠します。幅・折り畳みは再読み込みで戻ります。

演出テスト：塵、ランタン光の揺らぎ、霧、雨と水しぶきをCanvasで重ねます。「演出テスト・調整」で塵の粒数、光の揺らぎ、霧・雨の強さ、風向きを即時変更できます。塵と光は点灯後、天候は既定で入口だけです。屋外限定チェックを外すと室内でも試せます。停止・初期値へのリセットもできます。30fps上限、解像度1.5倍上限、非表示タブでは描画停止。動きを減らすOS設定では静止します。音や立体的な影、水面の物理計算は含みません。

入力欄の宛先にはGMも含みます。GMを選んで送信すると入力した質問にGMが答えます。全員への送信にGMの返答は含めません。

人物の奥行き：足元を上げ、奥ほど縮小する簡易2.5D配置です。探索では3人を左右の離れた範囲にランダム配置し、シーンへの入場時だけ更新します。戦闘ではイネスを含む4人を左手前、番人を右奥へ配置します。敵の予告は人物に重ならないよう行動欄の直前へ表示します。ブロムの体格は他の人物の90％を基準にしています。「演出テスト・調整」の奥の縮小率（初期25％）、奥の足元の高さ（16％）、人物の基準サイズ（46％）で比較できます。「立ち位置を配置し直す」は表示だけを更新し、ゲーム状態や判定に影響しません。値は再読み込みで戻ります。厳密な地面投影や射程計算は行いません。

調査ラベルは人物画像・シーン見出し・出口・他のラベルから8pxの余白を確保できる近い位置へ移します。人物のランダム配置、サイズ調整、シーンのリサイズ、画像の読み込み時に再計算します。

発見型ギミックの試作：入口で点灯 → イネスの「周囲の痕跡を探す」 → 個別の発見を仲間に伝える → リディアの解読提案を実行 → リディアに解読内容を聞く → 消灯 → 蒼白い塵が集まる場所をクリック → 再点灯して収納を調べる → 錠前の発見を共有 → ガレスの解錠提案を実行 → 灯石を取得します。灯石は消灯したまま足元を照らせます。解読・解錠の候補は能力と既知の手がかりを検証し、提案後に実行ボタンを出します。点灯・消灯は最初から使える基本能力で、解読なしで消灯して発見する別順序も可能です。既存の台車や石扉などの選択肢は従来どおりで、すべての謎を発見型へ変えたわけではありません。

キャラクターシートには基本能力の実行／依頼を用意しました。能力の相談はフッターの入力欄から行います。AIによる発見の共有は所有する手がかりのキーだけ受理し、解読内容は本人に渡して会話で共有します。自分の個別情報には共有ボタンがあります。入口で「ヒント」「次に」「どうすれば」「何をすれば」を含むGM相談は、公開状況と共有済みの手がかりに基づく段階的な定型ヒントです。それ以外の質問は入口でも既存LLMが答えます。停滞の自動判定・任意のギミック生成・汎用エディタ・永続保存はありません。明示した点灯・消灯・解読・収納の解錠はJSが確実に実行し、相談の返答と提案は実LLMを使います。

雷光：雨のある坑道入口では初回約3.5秒後、以降7〜15秒の間隔で稲妻が走り、景色が一瞬明るくなります。光は0.75秒で減衰します。「演出テスト・調整」の雷光の強さ（初期55）と「雷光を試す」で比較できます。強さ0では表示しません。手動テストはどのシーンでも使えます。動きを減らすOS設定では自動発生を止め、手動の光量も抑えます。非表示タブでは時間を進めません。雷光だけで調査ポイントが開示されることはありません。ドラゴンの登場イベントとの接続は今後の実装です。

システム設定：GMの近くの歯車から右側の設定パネルを開きます。通常画面から「最初から」「演出テスト・調整」を移し、ゲーム管理・音声設定・開発調整をまとめました。会話欄を畳んでも歯車を利用できます。Escapeまたは×で閉じます。開発調整のチェックを有効にすると既存の演出スライダーを表示します。クロニクルはこの卓の会話とGMの記録を閲覧しMarkdownへ出力する簡易版です。エラーや未共有の個別情報、隠し状態は出力しません。mock2の戦績・創作資料などを含む完全版ではありません。サウンド・音量・TTS・STTは未接続として表示し、動かない操作は置いていません。設定は再読み込みで戻ります。

ダイス判定：戦闘の「作戦を実行」は、作戦・補正・リスクを確認するGM判定画面を開きます。GMに頼むとD20を1判定1回だけ振り、出目＋補正＝合計／目標10を表示します。見抜く＋5、弱点＋5、支援後の次のリディアの攻撃＋5は既存ルールのまま。支援・かばうでは振りません。振る前はキャンセルできます。振り始めた後は結果が出るまで閉じる操作とEscapeを止め、見えた出目を選んで振り直すことを防ぎます。全判定の表示後に確定し、会話とクロニクルへ記録します。仲間の結果への反応は今回は定型文です。

探索の判定は隠し収納の解錠だけ。ガレスの錠前破り＋3、イネスの任意支援＋2。合計10以上は静かに解錠、5〜9は解錠できるが音で奥の敵が警戒、4以下は開かず音が響きますが構造を把握して以降＋2。報酬は灯石1個で、重複取得は不可。初回の成功／代償つき／失敗は支援なし70／25／5％、支援あり80／20／0％です。発見・点灯・解読などは従来の確実な反応を維持します。GMの設定→開発調整→「ダイス演出を試す」でゲーム状態を変更しない表示テストができます。回転1250ms＋着地1050ms、動きを減らす設定では80msでアニメーションなし。判定の物理シミュレーション、世界側の遭遇判定の新規実装、汎用判定エディタはありません。

## 固定リーダーを置かない戦闘連携（2026-10-04）

イネスは自分の行動だけを選び直せます。AIの行動は本人が選択し、調整時にも本人だけが変更できます。上下の順番変更は提案であり、全員を強制的に動かす権限ではありません。「仲間と連携を調整」でGMが現行ルール上の食い違いを整理し、各AIが1回ずつ返答します。支援がリディアの攻撃より後にある場合は前へ移す案を提示します。実行には3人の本人の了承が必要で、拒否・不正応答・接続失敗では進行しません。行動や順番を変更したら以前の了承は使いません。AIが行動を変えた場合は次の確認を手動で行い、自動で何巡も相談しません。

各キャラクターは「退路を確保する（撤退希望）」を選べます。攻撃側と撤退側が分かれた場合、撤退希望者は攻撃せず自分への反撃を半減（端数切り上げ）、他の仲間は選んだ行動を行います。1人の意見で全員を撤退させず、全員が撤退を選んだ場合だけ反撃・ダイスなしで撤退します。これは既存のターン戦闘内で試す暫定ルールで、個別の別シーンへの離脱やリアルタイム戦闘は未実装です。味方を火球に巻き込む判定は現行ルールにないため、今回も追加していません。探索でAI同士の呼びかけから自律実行する機能はまだ未実装です。

動作確認：実AIの3人が混在した撤退・攻撃を了承し、実行ボタンが有効になることをブラウザーで確認しました。支援→火球の順番で補正＋5が適用され、撤退希望のブロムは反撃2、攻撃したガレスは反撃4、ラウンド2へ進みました。別の試行でAI自身が行動を変更した場合、実行が無効のまま再確認になることも確認しました。ブラウザーの警告・エラーは0件。
