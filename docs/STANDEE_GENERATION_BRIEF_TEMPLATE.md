# 二面図/三面図の生成依頼テンプレート

`【】` の中だけを書き換えて、そのまま Codex(`/codex:rescue --fresh --wait`)へ渡す。
それ以外は毎回同じで、すべて実際の失敗から出た条項である。根拠は
`STANDEE_TURNAROUND_SPEC.md` の第8節。

受け取ったら `npm run accept:standee <出力パス>` を走らせ、**画像を目で見る。**

---

【キャラ名】の立ち絵を、**前面と背面を1枚にまとめた二面図**として生成してください。
（ポーズを検証したい段階なら「三面図（前面・側面・背面）。並び順は左から前面→側面→背面」に置き換える）

必須:
- imagegen Skill を使用すること
- **1回の生成で1枚の横長画像として描かせる。前面と背面を別々に生成しないこと**
- 並び順は左が前面、右が背面

作業前に確認する画像:
- 【画調の基準になる既存キャラの前面PNGの絶対パス】
  画調はこれに合わせる（写実寄りの重厚な塗り、くすんだ色調、革と布の質感、線ではなく陰影で形を作る）
- 【同一性の基準になる、そのキャラの既存PNGの絶対パス】
  顔・体格・衣装の同一性はこれを引き継ぐ

描く内容:
- 【キャラの説明。衣装】
- **ポーズ: 【ポーズ】**
- 両足は肩幅、両足とも接地、体重は均等。頭は正面向きで傾けない
- **動作はすべて画面と平行な面に収める。手前や奥へ突き出す動きを描かない**
  （平らなアクリル板の駒にするので、手前に向いた要素は消えてしまう）

前面図と背面図で必ず揃えること:
- 同じ身長・同じ頭身・同じ体格。両図の頭頂と靴底を同じ高さに置く
- 同じポーズ。腕の角度、脚の開き、体重のかけ方、頭の傾きまで
- 両足の接地位置と高さ
- 左右の規則: **前面図は「人物の右＝画面の左」、背面図は「人物の右＝画面の右」**
  【装備がどちら側にあり、前面図と背面図でそれぞれ画面のどちらに見えるか】
- **背面図は前面図の鏡像ではない。** 背中の造作（背当て、上着の背中の合わせ、
  帯の吊り方、後頭部）は背面固有の情報として描く

**背面図で見えない部位:**
- 【体の前で働いている手・武器・持ち物】は、真後ろから見ると胴に隠れて見えません。
  **描かないでください。** 見えるのは【上腕など、胴からはみ出す部分】だけです
- **宙に浮いた手や持ち物を描かないこと**
  （※シルエットに優しいポーズは、背面図に描くものが無いポーズでもある。
    明示しないとモデルが空白を埋めようとして嘘を描く）

画像の形式:
- **透明背景のPNG。** 白背景・板・外枠・地面の影・接地線・文字ラベルを入れない
- 横長。**生成できる最大のネイティブ解像度で出力する。生成後に拡大しないこと**
- **despill（緑かぶり除去）を人物全体にかけないこと。** 縁のフリンジは許容します。
  後段のパイプラインが透明部分のRGBを人物の縁の色で埋めるので実害がありません。
  色を守る方を優先してください
- 生成時の背景色は**緑を避け、中間グレーにする**方が安全です
  （茶色の人物から緑を抜くと紫になります）
- アルファチャンネルだけを作り、**人物のRGBには手を加えないこと**

出力先: 【絶対パス。-turnaround.png または -threeview.png で終わること】
- 既存ファイルを上書きしないこと

制約:
- 2D画像だけを扱う。Blender・GLB・ゲームコード・スクリプトを変更しない
- **切り抜きや型抜きで辻褄を合わせないこと。** 既存画像のアルファを流用して
  人物を切り抜くのは禁止
- 生成後に、画像寸法・四隅のアルファ・**人物部分のR/G/Bの平均値**を報告すること。
  G/R が 0.7 前後なら正常、0.45 を下回れば緑の抜きすぎ
- 拡大や後処理をした場合は必ず報告する
- 切り分けと検査はこちらで行う。**1枚の図を出力するところまで**が仕事
- 透明背景を確認できない場合は、採用せず失敗として報告する
