# 通しプレイ録画台本 — ランタンヒル年代記 第1話「廃坑の灯」

2026-08-19に実機(Chrome / Gemini `gemini-3.5-flash-lite`)で**最後まで通した経路**をそのまま書き出したもの。
推測ではなく、実際に通った宣言の列である。所要は判定の成否で伸縮するが、実測で**おおよそ12〜15分**。

## 前提

```bash
# 1. LLM中継サーバー(8788)
cd trpg-gm-mock2 && node server.cjs

# 2. 画面(5173)。NO_SSL=1で証明書の警告を出さない
cd trpg-gm-mock2 && NO_SSL=1 npx vite --port 5173 --strictPort
```

- ブラウザは **http://localhost:5173/** 。ウィンドウは16:9に近い形(実測 1440×723 で撮影確認済み)
- 起動したら必ず **「最初から」** を押す。「続きから」だと途中の状態から始まる
- 右パネルの「使用モデル」「トークン消費(通算)」は**運用コストの実測が映る**ので、
  社長向けなら一度開いて見せる価値がある

## 経路の全体像

```
導入(マイラの依頼)
  └ 場面1 坑道の入り口
      └ 場面2 分かれ道 ──左── 場面5 崩落した場所(蝙蝠戦・回復薬・機械人形)
                        └─右── 場面6 柵のある場所(錆喰い戦)
                                  └ 場面3 灯りの部屋(番人)
                                      └ 場面7 奥の間(心石の欠片)
                                          └ 場面4 村にもどる
                                              └ 結末(マイラへ渡す)
```

左を先に回るのは、**場面7へ進む条件に場面5の秘密(s5c)が要る**ため。順番を入れ替えると奥の間へ入れない。

## 録画

macOS標準で完結する。**ffmpegは不要。**

```bash
screencapture -v -V 900 -k ~/Desktop/Terminus/videos/mock2_playthrough.mp4
```

- `-v` 動画、`-V 900` 15分で自動停止、`-k` クリックを表示
- ナレーションを同時に入れるなら `-g` を足す(既定の入力から音声を録る)
- **初回は「画面収録」の許可が必要。** システム設定 → プライバシーとセキュリティ → 画面収録 で
  ターミナル(またはClaude Code)を許可し、**アプリを再起動**する
- ワンテイクで撮れば編集は発生しない

## 撮影中に避けること

- **判定中に連続で入力しない。** 2026-08-19時点では直っているが、着地表示のまま止まる不具合があった(`97475d5`)
- **「続きから」を押さない。** 途中の状態から始まり、台本と噛み合わなくなる
- 場面4で `マイラの家へ進む` と言わない(#35参照)
